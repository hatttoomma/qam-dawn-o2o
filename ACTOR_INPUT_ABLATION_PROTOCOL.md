# Residual actor input ablation

Authorized scope: Task1 and Task2, seed 0, QAM offline 500k followed by 50k primitive online steps. Keep the previous plain-TD, batch 256, UTD 0.25 configuration. Inherit each task's current and target critic; freeze the full QAM base. Preserve online-only chunk replay, horizon 5, scale 0.1, 20k base-only warmup, 7,500 updates, learning rates 1e-4, target tau .01, min10 actor and target aggregation, actor entropy and automatic alpha, target entropy -25, and gradient clipping 50.

Run a fresh paired control and treatment on each task. Both actors have 62 inputs, three 256-unit ReLU layers and two 25-dimensional Gaussian heads. The first 37 inputs are the current observation. The control masks the final 25 inputs to zero; the treatment supplies the exact base action chunk used in the composition. Both use identical parameter, optimizer and RNG initialization. The input mask is static configuration and is recorded separately from serialized trainable state. Gaussian sampling, tanh, scale and action clipping remain unchanged.

Compared with the historical 37-input actor, both new arms have 6,400 additional first-layer weights and 160,562 total actor parameters. The new paired control is the primary comparator; historical results are contextual because actor initialization changes with the input width. The control's masked weights have zero gradient. Treatment gradients can use those weights. Network initialization is not selected using evaluation performance.

Current and next base action chunks already exist in replay. Actor training, collection, evaluation, alpha training and next-action generation must all use the same input rule. The critic still sees observations and final summed actions, and retains the exact pretrained backbone. Original training files and training loop remain unchanged. actor_input_agent_patch.json records every source change to the agent.

Before formal training, run 60-step/20-step-warmup smokes for all four arms. Check task checkpoint provenance, identical full initial trainable states, input masking/gradient behavior, state-only functional projection, ten expected updates and valid evaluation/diagnostic outputs. Freeze training/protocol sources and runtime metadata before formal runs.

Primary endpoint: sampled-residual success rate and mean raw episode return over 100 fixed evaluation reset seeds. Seven prespecified curve checkpoints use 50 episodes. Mean-residual evaluation uses 50 episodes and is secondary. Base action sampling remains stochastic. Report all arms, failures and any repeated-evaluation differences without selecting better repeats. Validate frozen base, unchanged agent across final evaluations, update count, finite training metrics, full warmup replay equivalence with explicit floating-point tolerance, fixed probes and raw episode aggregation. This is one training seed; no across-seed superiority claim.
